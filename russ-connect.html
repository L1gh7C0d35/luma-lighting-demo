Russ, here's how to connect your lights.

Use desktop Chrome or Edge on the computer attached to the equipment. The main studio stays in your browser. No developer's Mac is required.

Where to click, just like the Lightkey reference

Look in Luma's upper-left corner beside your project name and No output. Click DMX OUTPUT. Choose your connection method on the left, then follow its steps on the right.

1 · DMX OUTPUT

Upper-left button next to the show name.

2 · Choose interface

USB, Art-Net, sACN, or optional OLA.

3 · Match your fixtures

Exact device, fixture model, DMX mode and address.

4 · Safety first

Bench-check in simulation; arm only after verification.

Which one do you have?

USB CABLE TO COMPUTER

USB-DMX interface

  1. Plug the supported interface into this computer.
  2. Choose USB Interfaces in Luma.
  3. Select the exact make/model printed on the device.
  4. Click Choose USB-DMX adapter and approve the browser's device picker.

If your model isn't listed, don't guess by selecting a generic serial port. Some adapters require their own drivers or aren't browser-compatible.

ETHERNET OR WI-FI NODE

Art-Net / sACN

  1. Install the optional Luma Bridge preview for your Mac or Windows computer.
  2. Open its local pairing page at 127.0.0.1:18787 on that same machine and copy the private code.
  3. In Luma click Connect local bridge; approve Local Network Access when Chrome/Edge asks.
  4. Paste the code and type the lighting node's actual private IPv4 address.

Art-Net and sACN send UDP through the optional local bridge. The webpage itself cannot send UDP directly.

SPECIALIST HARDWARE

Other / OLA

  1. Check the interface's manufacturer and exact model.
  2. If the device needs a local driver/OLA service, choose Other / OLA.
  3. Set up the supported driver/ports separately and inspect the local device list.

Not all Lightkey-compatible USB interfaces work directly from the browser. Do not substitute a different model.

Never arm until the physical rig is verified

Import the correct source-pinned Open Fixture Library profile and match the fixture's real DMX mode, address and universe. Check movement/bright-light hazards and an independent physical power cutoff. Luma requires separate arm confirmations. STOP USB OUTPUT or STOP NETWORK OUTPUT stays available while live, but no software packet guarantees a lamp is dark.

For an exact compatibility check: Send the adapter manufacturer's name and model, plus each light's fixture model, DMX mode and address. Photos of the labels/screens are helpful. You do not need to arm anything just to identify it.

Developer preview: supported browser/device combinations and bridge downloads are not physically certified; Mac Apple Silicon and Windows package execution has not yet been verified on those platforms. The guide never performs device discovery or sends lighting output.
